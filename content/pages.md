# Work, Try it, Journal, Contact — prose drafts in Patrick's voice

## Work
**Intro:** Case studies, not source. Most of this work is private and belongs to the organizations it serves, so each piece names the problem, what was built or decided, how it was governed, and the honest outcome, including the ones where the right answer was to stop.

Order and one-line framing (full bodies carry over from the current site):
1. **Governed AI-agent platform** — the decision that mattered: no agent runs unattended until a person has approved the exact list of operations it may perform.
2. **County AI and AI-governance roadmap** — in progress; the decision: write the roadmap with the county's own IT team, not for them.
3. **Melon Code** — the decision: run the whole coding-agent loop on a model we own, and point Claude Code at it to learn how the loop really works.
4. **Local inference at the edge of one GPU** — the decision: measure before optimizing; three speculative-decoding routes closed with break-even math, one small change kept.
5. **A phone-sized model, built from nothing on one desk** — the decision: start from random weights and a 27B teacher, pre-register everything, publish the journal.
6. **MelonStudio** — the decision: stop. A negative result measured honestly, and the reason the later work moved to llama.cpp.
7. **Engineering with people and agents** — the decision: write the operating model down so people and agents work the same way, with a gate on every pull request and a ledger for the shared machine.
